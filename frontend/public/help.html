PowerProbe Help Documentation

Use this quick guide to operate the dashboard. The full project manual is available in the repository at frontend/docs/README.md and WORKING_MANUAL.md.

Run A Test

  1. Open Dashboard.
  2. Use Configuration to set charge or discharge values.
  3. Click Run to start a Pi-backed session. If the Pi is unavailable, bundled demo telemetry runs automatically.
  4. Click Stop to end the session and reset live values to zero.

Review History

Open History Analytics to filter completed sessions by battery, mode, and date range. Charts and exports update from the filtered selection.
